Welcome to spectral_density_fit's documentation!
=================================================

**spectral_density_fit** is a Python package for performing few-mode quantization of arbitrary electromagnetic spectral densities. The package implements the methods described in:

1. \I. Medina, F. J. García-Vidal, A. I. Fernández-Domínguez, and J. Feist, *Few-Mode Field Quantization of Arbitrary Electromagnetic Spectral Densities*, `Phys. Rev. Lett. 126, 093601 (2021) <https://doi.org/10.1103/PhysRevLett.126.093601>`_

2. \M. Sánchez-Barquilla, F. J. García-Vidal, A. I. Fernández-Domínguez, and J. Feist, *Few-mode field quantization for multiple emitters*, `Nanophotonics 11, 4363 (2022) <https://doi.org/10.1515/nanoph-2021-0795>`_
